# Knowledge maintenance

Use these skills for short routing and durable workflow details. Use [the art direction](../../../ART-DIRECTION.md) for implementation choices and evidence. Use the existing W6–W8 notes for gameplay and networking.
When finishing a pass, record the affected maps, shader and material assumptions, evidence paths, performance context, and remaining playtest needs. Distinguish a staged Unity render from the live match. Preserve separate records of rejected experiments and planned improvements.
Update only skills whose workflows or evidence changed. Keep generated builds, raw logs, and snapshots by the task outputs rather than in a skill directory.
